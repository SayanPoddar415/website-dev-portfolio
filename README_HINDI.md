# Website Design Portfolio

## फ़ोल्डर में क्या है?
- `index.html` — वेबसाइट की सामग्री और sections
- `css/style.css` — रंग, layout, cards और responsive design
- `js/main.js` — menu, theme toggle, filters, FAQ और WhatsApp enquiry

## इसे अपने कंप्यूटर पर कैसे चलाएँ?
1. ZIP extract करें।
2. `index.html` को Chrome में खोलें, या VS Code में folder खोलकर Live Server इस्तेमाल करें।
3. मोबाइल पर भी preview करके देखें।

## ज़रूरी बदलाव करने से पहले
1. `js/main.js` में `WHATSAPP_NUMBER` को अपने वास्तविक WhatsApp number से बदलें।
   - भारत के नंबर के लिए country code 91 के साथ लिखें।
   - उदाहरण का format: `919876543210` — यह केवल sample format है।
2. HTML में `enzos.collabs@gmail.com` को बदलें अगर दूसरा email इस्तेमाल करना है।
3. Packages की कीमतें sample starting prices हैं। अपने काम, समय, domain/hosting और दूसरे खर्च के हिसाब से तय करें।
4. Portfolio cards पर साफ लिखा है कि वे sample concepts हैं। इन्हें असली client projects न बताएं।
5. Premium/e-commerce features बेचने से पहले सुनिश्चित करें कि आप उन्हें सच में बना और maintain कर सकते हैं।

## क्या तस्वीरें इस्तेमाल हुई हैं?
इस version में external/local portfolio photos हटाई गई हैं। Website previews HTML और CSS shapes से बनाए गए हैं, इसलिए पुराने `logos/`, `packet/` और `tshirt/` image folders की जरूरत नहीं है।
